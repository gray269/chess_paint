# Contribuer

Les améliorations sont bienvenues, notamment pour :

- affiner les seuils de qualité des coups ;
- reconnaître les fourchettes, clouages et attaques à la découverte ;
- ajouter plusieurs styles de peinture ;
- améliorer l’estimation du niveau ;
- afficher un véritable échiquier lié à la liste des coups.

Avant une proposition de modification :

```bash
npm install
npm run build
```

Le code doit rester exécutable sans serveur applicatif ni collecte de données.
